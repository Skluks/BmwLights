# BMW Lights

Световые эффекты для BMW E60/E61 LCI через OBD и Bluetooth-адаптер vLinker (BM/BM+).

> ⚠️ Только на стоящей машине. При остановке эффекта и уходе приложения в фон свет возвращается машине.

## Как работает
Телефон → Bluetooth → vLinker → D-CAN → шлюз → модуль света LM (0x70).
Адаптер настраивается как в Deep OBD/EdiabasLib (raw CAN 500k, запросы 0x6F1, ответы 0x600+адрес).
Лампы включаются KWP2000 `30 <LID> 07 <состояние>`, возврат машине — `30 <LID> 00`.

## Первая настройка
1. Зажигание включено, BimmerCode/BimmerLink закрыты.
2. Подключение → Искать → vLinker.
3. Лампы → Сканер выходов → «Найти выходы» (только чтение).
4. Выберите выход → «Включить» → отметьте, что загорелось.
5. Если сканер просит сессию — укажите 86 или 89 в настройках.

Без машины — режим «Демо без машины» (симулятор модуля света).

## Сборка
